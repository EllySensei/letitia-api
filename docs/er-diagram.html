Table roles

  • Main entities: clients, packages, rental_items, consumables, users (login accounts)
  • Transactions / logs: events (bookings), payments, return_logs
  • Junction tables (many-to-many): package_items, event_items, event_consumables

Many-to-many relationships

  • packages ↔ rental_items through package_items
  • events ↔ rental_items through event_items
  • events ↔ consumables through event_consumables

System tables (not shown)

  • notifications: alerts in the bell menu
  • change_log, data_versions: record of every change, used by the Database tab
